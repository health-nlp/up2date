# UP2DATE: Shared Task on Systematic Review Updates

UP2DATE @ SCOLIA 2027 is a shared task focusing on the development of new methods to assist in updating systematic reviews. More information: https://up2date.health-nlp.com/

For 2026, we provide:

 - Topics in the form of the initial versions of the reviews: `2026/initial`
 - Correctly formatted runs of our baselines as example submissions: `2026/baselines`

 Once the shared task is over, we will share the updated versions of the systematic reviews in `2026/updated`, along with all of our evaluation scripts we use to evaluate submissions.
